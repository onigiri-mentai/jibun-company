# 手作りの社内資料と、整った操作基盤

配色・フォント・レイアウト・タップ領域を維持し、輪郭と影だけを `dist/handcraft.css` に分離しています。データ処理・案件登録・編集・完遂・報酬・保存のJavaScriptは変更していません。

## 共通クラス

- `sketch-frame`：通常の紙枠。`sketch-frame--strong` を併用すると主役の書類用の少し太い輪郭。本社の大カード、受注票、案件票、会社成長のお知らせ等に使用。
- `sketch-button`：既存の角丸・背景・サイズの上に、控えめなペンの輪郭を重ねます。主要ボタン用。中央ナビの受注ボタンには適用しません。
- `sketch-divider`：書類内の軽く揺れた区切り線。`sketch-divider--quiet` でさらに弱めます。

輪郭はCSS変数に持つ小さなSVGマスクで再利用しています。画像ファイルの追加、ランダム処理、文字や画面全体を歪めるフィルターは使いません。スクロールするシートは背景に輪郭を描き、スクロール中の文字に枠が重ならないようにします。装飾の擬似要素は `pointer-events:none` です。必要に応じて `--sketch-ink`、`--sketch-ink-strong`、`--sketch-shadow` を調整できます。

## 適用しない場所

EXPバー、数値の集計、入力欄、案件・履歴の細かい行、下部ナビは基本の整った線を維持。実績の見出しにだけ軽いファイルラベル風のアクセントを入れます。読みやすさを損なう場合は手描き装飾を外してください。

## 実装上の注意

装飾は枠の寸法・余白を変更しません。ネイティブdialogはfixed配置を保持し、イベント用紙の自動縮小・閉じるボタンの専用行も従来どおりです。紙の影は薄い柔らかな影、ボタンは押せる軽い段差を残します。

参考画像に合わせた調整：本社カードは濃い茶色で線幅に小さな変化を付け、イベント用紙は角丸カードではなく四隅のある紙の輪郭に分けています。会社レベルの小枠はサイズに合わせた丸みを使用。書類内の線は細いペン線で、影は引き続き薄くしています。

実績の見出し直下に重なっていた短いアクセント線は廃止。花丸は赤ペンの小さな手描きSVGで、期限内完遂の時だけ表示します。フォントは外部の分割読込をやめ、同梱WOFF2の400・700・900を使用。500・600・800の指定は利用可能なウェイトに整理し、ファミリーとフォールバックも共通化しています。
