# じぶんカンパニー

日常の小さな行動を、自分の会社を育てる案件へ。落ち着いた社内端末と、異常に盛大な受注・完遂のお祝いを組み合わせたスマートフォン向けWeb試作です。

[公開アプリ](https://onigiri-mentai.github.io/jibun-company/)

本社 / 案件 / 受注 / 実績 / 総務の固定ナビ。任意の締切、難易度別の報酬、会社成長、設備、社内表彰、完遂履歴、会社名変更、効果音、控えめな演出、データ書き出し・復元に対応。結果は「閉じる」まで表示します。アイコンは独自のSVG、フォントは丸みのあるゴシックです。

## 起動

`python -m http.server 8000` を実行し `http://localhost:8000` を開きます。外部フォントが取得できない場合は端末のフォントへフォールバックします。フレームワークやビルドは不要。

ソースは `dist/`、ルート `index.html` は同じアプリをGitHub Pagesから読み込むエントリです。変更後は `python build.py` でエントリとダウンロード用の単一HTMLを更新します。

## 検証

`node check.cjs` で旧データ移行・二重完遂防止・成長条件・日付境界を検証。`browser-check.cjs` はPlaywright/Chromiumがある開発環境用。実機iPhoneでの音声・キーボード・Safe Area確認は別途必要です。

データはブラウザのlocalStorageに保存。総務部からJSONバックアップできます。通知は本社を開いたときの期限案内で、バックグラウンド通知はありません。

[将来のアプリ化と責務分離](docs/mobile-roadmap.md)：まずCapacitorを検討し、必要に応じてネイティブUIへ移行する方針。今回の変更では技術移行はしていません。

`event-layout-check.cjs` は受注・完遂・会社成長の用紙と閉じるボタンが、短い画面・横向き・表示領域の変更後にも収まることを検証します。Safariのブラウザバーによる高さ変更には Visual Viewport を使用しています。

オフィスの背景・机・椅子は、ユーザー提供のJPEGを `dist/assets/office/` に分けて配置しています。白い背景はCSSのmultiply合成で馴染ませ、元画像は変更していません。植物・PC・棚は引き続きSVGで、レベルに応じて表示します。単一HTML版にはJPEGを埋め込みます。

机・椅子は背景透過PNGへ更新。家具は通常合成で、物体内部を不透明に保ちます。背景のJPEGだけは最背面でmultiply合成を使用。元のJPEGは保管しています。

案件票に任意のひとことメモを追加できます。カード本体は案件票を開き、左のチェックのみが完遂操作です。案件票からも編集・完遂できます。編集は実績を加算せず、完遂時に更新後の難易度の報酬とメモを記録します。旧案件のメモは空欄として移行。`note-check.cjs` でこの操作の分離・保存・編集・会社成長を確認します。

[手作り社内資料のデザインルール](docs/design-system.md)：共通CSSの強い紙枠・控えめなボタン・軽い区切り線を説明しています。情報の多い一覧と下部ナビは従来の整ったUIを維持。

完遂履歴から総務部の保管済み案件票を開けます。今後の受注日時・完遂時点のメモ・期限・難易度・実際の獲得EXPを保存。期限日の終わりまでに完遂した案件にのみ花丸を表示します。古い日時は補完しません。日本語フォントは同梱のZen Maru Gothic（400/700/900）を使い、フォントライセンスは `dist/assets/fonts/OFL.txt` に保管しています。`archive-check.cjs` は保管票・期限日境界・旧データ・スマホ表示とフォント読込を確認します。
