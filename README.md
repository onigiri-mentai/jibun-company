# じぶんカンパニー

自分自身をひとつの会社に見立て、日常のタスクを「案件」としてこなす、スマホ向けタスク管理ゲームのプロトタイプです。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「＋ 新規案件」から案件名と難易度を入力し、「案件を受注する」を押します。
3. 実際にタスクを済ませたら、案件カードをタップして完了します。
4. EXPを貯めて会社を成長させましょう。Lv.2で観葉植物、Lv.3でPCと棚が増えます。

右上の「♪」で効果音を切り替えられます。案件と会社の成長はブラウザのlocalStorageに保存されます。別端末との同期はありません。

## 構成

- `dist/index.html`：画面
- `dist/style.css`：デザインとアニメーション
- `dist/app.js`：案件・報酬・レベル・保存処理
- `index.html`：直接開ける1ファイル版
- `check.cjs`：動作ロジックの確認（`node check.cjs`）

HTML / CSS / JavaScriptのみで動作し、インストールやビルドは不要です。Google Fontsを読み込めない場合は端末のフォントで表示されます。

GitHub Pagesを使う場合は、Settings → Pagesで「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` を選択してください。
