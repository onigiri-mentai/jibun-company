# じぶんカンパニー

自分自身をひとつの会社に見立て、日常のタスクを「案件」としてこなす、スマホ向けタスク管理ゲームのプロトタイプです。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「＋ 新規案件」から案件名と難易度を入力し、「案件を受注する」を押します。
3. 実際にタスクを済ませたら、案件カードをタップして完了します。
4. EXPを貯めて会社を成長させましょう。Lv.2で観葉植物、Lv.3でPCと棚が増えます。

右上の「♪」で効果音を切り替えられます。案件と会社の成長はブラウザのlocalStorageに保存されます。別端末との同期はありません。

## 構成

- `dist/index.html`：画面
- `dist/style.css`：デザインとアニメーション
- `dist/app.js`：案件・報酬・レベル・保存処理
- `index.html`：直接開ける1ファイル版
- `check.cjs`：動作ロジックの確認（`node check.cjs`）

HTML / CSS / JavaScriptのみで動作し、インストールやビルドは不要です。Google Fontsを読み込めない場合は端末のフォントで表示されます。

GitHub Pagesを使う場合は、Settings → Pagesで「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` を選択してください。

## 小さな会社の社内文化

- 初回起動時に会社を設立できます。会社名は「総務部（設定）」から変更でき、ホーム・号外・売上伝票・増築発表に反映されます。
- 案件の締切は任意です。「今日」「明日」「今週中」（日曜まで）または端末標準の日付選択で設定できます。期限は端末の現地時間で判定します。
- 受注は営業部の号外、完遂は経理部の伝票とハンコ、会社成長は増築発表とくす玉でお祝いします。
- 効果音は右上の「♪」で切り替えられます。受注ジングル・完遂の成功音・会社成長のファンファーレはWeb Audioで合成します。端末が対応していれば振動も使います。
- 演出は以前よりゆっくり進み、結果画面は自動では閉じません。最後の「閉じる」で本社へ戻ります。会社成長がある場合は「会社成長のお知らせへ」から専用の発表を読めます。「演出を早送り」または Escape は結果まで進める操作で、画面を閉じません。
- 既存の案件・会社EXPを引き継ぎます。動きを減らす端末設定ではフラッシュと動きを省きます。

## 実績帳と文字の雰囲気

本文は丸みのある Zen Maru Gothic、見出しは手書き風の Yomogi です。フォントを読み込めない場合は端末のフォントで表示します。

ホームの「業務実績」から、達成済み案件を日付ごとに新しい順で振り返れます。案件名・完遂時刻・難易度・獲得EXPをブラウザ内に保存し、再読み込みしても記録を引き継ぎます。

旧版は完遂後の案件名を保存していなかったため、実績一覧はこの更新後の完遂分から記録されます。以前の累計EXPは保持し、実績ページにも引き継いだ分として表示します。
